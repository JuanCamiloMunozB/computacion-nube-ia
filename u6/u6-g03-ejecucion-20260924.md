## 5. Preparar Airflow y ejecutar los cinco escenarios

Antes de iniciar Airflow, comprueba que la cuenta activa de `gcloud` pueda emitir el ID token que requiere la API privada:

```bash
gcloud auth print-identity-token >/dev/null && echo "ID token disponible"
```

Si Cloud Shell responde `No identity token can be obtained from the current credentials`, ejecuta `gcloud auth login --force` manualmente para renovar la autorización de la CLI y vuelve a comprobar. No cambies el servicio a acceso público; el DAG obtiene el token al llamar la API.

Instalar dependencias del laboratorio según la guía del curso. El DAG y la carpeta auxiliar deben copiarse juntos:


```sql

       alerta_calidad, alerta_umbral_actual, alerta_drift
```

```sql
SELECT fecha_lote, campo, COUNT(*) AS registros

UNNEST(JSON_VALUE_ARRAY(campos_error)) AS campo
GROUP BY fecha_lote, campo
```
